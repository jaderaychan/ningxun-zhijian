## 一、现在就要做的事（报名）

### 1. 打开官方页面
- 活动页：https://agnes-ai.cn/hackathon
- 页面上有 **报名二维码** 和 **活动群二维码**，扫码进入。

### 2. 准备报名材料
| 项 | 说明 |
|---|---|
| 账号 | 邮箱 / 手机号 / 验证码 |
| 个人信息 | 姓名、学校、学院、专业、学历、年级、**学生证**（仅用于在读身份核验，不对外公开） |
| 队伍信息 | 队伍名称、队长、队员、各成员的学校与专业构成 |
| 勾选同意 | 参赛规则、隐私政策、**学生独立完成原则** |
| 队长确认 | 「**必须使用 AGH、模型仅限 Agnes**」技术承诺，并保留时间与版本记录 |

### 3. 组别规则
- 每队 **1–3 人**，允许跨专业、跨学院、跨校组队。
- 全本科生 → 本科生组；**队伍里出现硕/博 → 系统自动归入硕博组**。
- 同一邮箱 / 手机号 / 学生证不得同时加入多支队伍。

### 4. 报名成功后立刻做两件事
1. **加入官方赛事群** —— 组委会在群里统一发放 **Agnes 自研模型调用 Key**。
2. 把 Key 交给我，我接进 AGH（也可以自己在 AGH 设置 → Provider 里填，Base URL `https://api.agnes-ai.cn/v1`，模型 `agnes-2.5-flash`）。

> 备用路径：也可以自行到 https://platform.agnes-ai.cn 注册申请免费 API Key（`agnes-2.5-flash` 与 `agnes-3.0-flash` 当前免费，图像/视频 flash 模型也免费）。

## 二、提交内容清单（全部必填）

| # | 材料 | 我们的产出方式 |
|---|---|---|
| 1 | **基本信息**：项目名称、参考方向（可多选）、项目摘要、问题来源与目标 | 我起草，你确认 |
| 2 | **技术信息**：AGH 作用、Agnes 模型名称/版本/环节/调用方式、数据/代码/专业软件/仿真环境/API 接口 | 从实际实现中提取，保证与代码一致 |
| 3 | **可运行作品**：在线体验链接 / 代码仓库 / 安装包 / 可复现运行说明 | 仓库 + README + 一键复现脚本 |
| 4 | **演示视频**：3–5 分钟，**仅提交链接**（1 个主链接 + 可选 1 个备用；如需访问码一并提交） | 用 ffmpeg 剪辑录屏 + 结果展示 |
| 5 | **运行证据**：AGH 执行记录、≥1 条工具/设备调用链、Agnes 模型参与核心任务证据、关键配置与专业验证结果 | 从 AGH 轨迹视图导出 + 验证器报告 |
| 6 | **测试样例**：正常、边界、失败三类 | 故障注入脚本 + 三类运行日志 |
| 7 | **成员声明**：成员分工、独立完成声明、第三方素材来源说明 | 我起草模板，成员确认 |
| 8 | **公开内容**：≥1 条真实项目内容（含平台、有效链接、截图与发布日期） | 知乎/B站/小红书/公众号任选其一发布 |

### 提交文件规格
- 单个 **ZIP ≤ 200MB**，命名：`组别-参赛编号-队伍名称-队长姓名`
- ZIP 可包含：代码、安装包、运行说明、演示视频、测试样例
- 超限时改用仓库或共享链接

## 三、评审维度（对照准备证据）

| 维度 | 我们要拿出的证据 |
|---|---|
| 问题价值与学科融合 | 研究区真实内涝问题陈述 + 地理/水文/AI 三学科方法说明 |
| 任务完成度与结果正确性 | D01–D05 五项客观指标报告 |
| Agnes Harness 与模型执行闭环 | AGH 轨迹：规划 → 工具调用 → 反馈 → 验证 → 重试 |
| 技术深度与系统实现 | 自研数值内核 + AGH 插件工程 + 双实现交叉验证 |
| **验证严谨性与异常处理** | 多源独立验证 + 故障注入三类样例 + fail-closed 证据 |
| 创新性与发展价值 | 「可自我验证的科学智能体」范式 + 可迁移到其他流域/事件 |

**两组采用不同评分权重**：本科生组更侧重任务完成度与结果正确性。
